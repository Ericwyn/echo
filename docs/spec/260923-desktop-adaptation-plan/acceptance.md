## 关键端到端脚本

1. **浏览→播放→返回**：在曲库筛选并滚动，播放歌曲，展开歌词，切队列，选择另一条但不播放，收起；原浏览位置不丢，音频未被选择动作改变。
2. **音量竞争**：设 20%，开启淡入淡出，快速下一首→暂停→播放，淡入中调至 35%，再断网恢复；最终遵从最后用户值，无瞬间跳到 100%。
3. **长队列**：当前位于第 1500 项，打开队列并定位，拖拽时模拟队列变更；取消过期拖拽，当前 entry 不错位；普通进度更新不打断浏览。
4. **系统与托盘**：UI 播放→系统暂停→托盘下一首→显示窗口→隐藏→再次启动→显式退出；每步同一曲目/实例/意图，没有重复控制或残留出声。
5. **失效回退**：系统总线/托盘宿主分别不可用或恢复，页面仍能控制播放；已隐藏窗口恢复到可找回状态，不把失败扩散到引擎。
6. **Android**：共享代码变更后，手机正常播放→熄屏下一首→通知栏远 seek→暂停→网络恢复；遵守原播放意图，回前台界面状态一致。
7. **Windows 封面与订阅（A12）**：本地中文/空格路径→离线→切到无封面→快速切歌→销毁重建 adapter；文本/封面属于当前曲目，旧回调不触发播放，封面失败不终止进程。
8. **原生架构与网络通路（A14）**：在目标 x64 环境运行最终 Windows 安装包，核对 native 库架构；分别验证 API/封面/下载/实际音频的直连与代理行为，不以登录成功代替播放验证。
