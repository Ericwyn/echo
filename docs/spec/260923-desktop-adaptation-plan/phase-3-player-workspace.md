# P3：播放工作区、歌词与宽队列

[返回 spec](README.md) · [总体设计](desktop-adaptation-plan.md) · [验收](acceptance.md)

状态：首轮实现中。封面固定、歌词/队列右侧切换、封面动态背景、桌面常驻播放条和与进度条统一的细音量 scrubber 已落代码；桌面选中/双击语义、键盘焦点/快捷键、大队列性能与 Ubuntu 不同窗口尺寸验收尚待补齐。前置：P1 命令/快照契约、P2 shell 与常驻播放条已建立。后续：P4 联调系统入口，P5 验收性能和多平台。

## 目标与边界

按参考图完成窗口内播放工作区：左侧封面/歌曲信息，右侧歌词或宽队列。进入时收起资料库侧栏，返回时恢复浏览位置。底部播放条始终由同一个 shell 实例承载。

第一版实现单项选择、播放、定位当前、拖拽、移除和清空后续。队列搜索、多选批处理、删除撤销、浏览时停靠队列及悬浮歌词列入后续，不为它们新增第一版状态模型。

## 界面状态与操作

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| browse | 点击底部封面/歌词入口 | 进入 player-lyrics，保留浏览分支、筛选与滚动 |
| browse | 点击队列入口 | 进入 player-queue |
| player-lyrics | 点击队列入口 | 仅右侧换为队列，封面和底栏保持位置 |
| player-queue | 点击歌词入口 | 仅右侧换为歌词 |
| 任一播放工作区 | 再次点击底部当前模式按钮或点击收起 | 返回 browse；工作区内部 tab 点击只选择 tab，不关闭 |
| 任意界面 | Esc | 先关闭当前菜单/弹窗；再退出真正全屏；再收起播放工作区，每次只处理最上层 |
| 无当前曲目 | 点击歌词入口 | 入口禁用或呈现明确空状态；队列入口仍可查看已有队列 |

`browse/player-lyrics/player-queue` 是布局状态，不创建新的音频会话。切换发生在稳定根容器内；隐藏的浏览内容保留状态，但停止不可见动画与多余 ticker。登录失效、切库的行为沿用 P2 的导航/鉴权规则。

## 实施步骤

1. 新建桌面工作区编排，使用共享 cover、track identity、lyrics 与 queue content。通过 mode 状态控制内容，不复用手机全屏页面的整页 route/Hero 飞行动画。
2. 大窗口的封面上限先采用设计建议 320–400 逻辑像素；封面列、歌词阅读列与队列表格分别限宽。尺寸取实际内容约束，不能把播放器按窗口比例整体放大。
3. 空间不足时先降低封面尺寸，再将封面收为顶部歌曲摘要；队列/歌词保留主要空间，底部进度与播放操作始终可用。窗口高度不足时仅内容滚动，控制区保持可访问。
4. 歌词接入现有解析与同步组件，覆盖加载中、无歌词、错误重试、双语、大字体。用户手动滚动后暂停自动跟随，点击“回到当前”恢复；切歌重置到新歌曲，普通 tab 切换不错误重置到开头。
5. 歌词点击仍调用逻辑 seek，加载/转码期间显示真实忙碌状态。远距离连续点击以最后意图为准，不能另写一套寻址/重试算法。
6. 队列按宽度显示序号、封面、歌名/歌手、专辑、时长和动作。优先收起专辑等次要列；保留明确播放、移除或更多入口，不依赖鼠标悬停发现核心操作。
7. 界面选择使用 entry ID，与 currentEntryId 分开；单击选中、双击/Enter 播放按 D2 实现。手机/触控行为按 presenter 保留单击播放。右键菜单对正确条目操作，不改变实际播放位置。
8. 排序把手可见，鼠标拖拽无需先长按。保留 revision 校验；拖拽期间队列已经改变时取消本次排序并提示，不将旧 index 应用到新队列。重复歌曲始终按 entry ID 处理。
9. 定位当前：用户打开队列或主动定位时滚动到真正当前项；播放进度 tick 不拉回用户正在浏览的位置。保留滚动状态，远距离定位验证估算位置与最终对齐。
10. 清空后续与移除遵守既有队列方案。切换随机/循环不得重排用户的选择状态到错误条目；当前项被删除后的播放行为继续由 notifier 决定。
11. 增加应用内 Shortcuts/Actions：Space、Ctrl+F、Ctrl+Left/Right、Esc；列表 Enter 播放，Delete 仅在队列列表获得焦点时移除选中项。输入框、slider、菜单先处理自身按键，slider 上的 Space/方向键不同时触发播放切歌。
12. 选择性启用真正全屏；进入/退出时保存正常窗口状态，队列和歌词继续使用同一组件。不改系统标题栏样式来模拟全屏。

## 主要文件

`lib/features/player/pages/full_player_page.dart` 保留手机编排；新增桌面工作区文件；复用 `synced_lyrics_view.dart`、`player_scrubber.dart`、P1 队列内容和 `lib/widgets/song_list_item.dart`。P2 底栏的歌词/队列入口切到工作区，不再打开手机 bottom sheet。

## 验证与完成条件

- A05：1654 首实际量级和 5000 首构造队列可滚动、定位当前、排序；重复项/当前队尾/拖拽期间修改不会播错或删错。
- A06：歌词与队列切换不造成封面/底栏跳动或停止播放；收起后回到原浏览位置。大字体、无歌词与错误态不挤掉控制区。
- A07/A11：鼠标、键盘、触控语义分别验证；焦点可见，Esc 层级明确，输入搜索文本不会触发快捷播放。
- A15：队列保持懒构建，进度更新不重建全量行；在 release/profile 中记录连续滚动、切 tab 和缩放的帧耗时，不能用 debug 卡顿代表正式性能。
- 复用扩展 `test/features/player/play_queue_sheet_test.dart`、`synced_lyrics_view_test.dart`、`player_navigation_flow_test.dart`；增加桌面模式切换、焦点、选中与播放分离测试。
- Android 的全屏播放器、MiniPlayer、队列底部面板与 Hero 路径仍通过原有相关测试。
